# StudyMind AI

StudyMind AI is a full-stack AI learning assistant that allows users to upload files, ask questions about their content, and receive smart explanations using Retrieval-Augmented Generation (RAG).

The project supports PDF, Word documents, text files, code files, CSV files, and images using OCR. It also includes user authentication, saved chat history, response language selection, and different answer modes.

---

## Features

- User Sign Up and Login
- Saved chat history for each user
- Create and delete chats
- Upload and ask questions about files
- Supports multiple file types:
  - PDF
  - DOCX
  - TXT
  - MD
  - CSV
  - JSON
  - Python, JavaScript, HTML, CSS files
  - Images using OCR
- Each chat has its own vector database
- Prevents mixing content between different uploaded files
- Response language selector
- Answer modes:
  - Fast
  - Balanced
  - Deep
- AI explanations for:
  - Math
  - Programming
  - Algorithms
  - CV review
  - General study material
- LaTeX support for clean mathematical formulas

## How It Works

1. The user creates an account or logs in.
2. The user uploads a file.
3. The backend extracts text from the file.
4. The text is split into chunks.
5. The chunks are converted into embeddings.
6. The embeddings are saved in a chat-specific ChromaDB folder.
7. When the user asks a question, StudyMind AI retrieves the most relevant chunks.
8. The selected local AI model generates an answer based on the uploaded file content.

---

## Supported Answer Modes

### Fast
Uses a smaller model and fewer retrieved chunks for quick answers.

### Balanced
Uses a balanced model and moderate context for general questions.

### Deep
Uses more context for detailed explanations and deeper analysis.

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/moneebyusuf/StudyMind-AI.git
cd StudyMind-AI
```

---

## Backend Setup

```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Run the backend:

```bash
uvicorn app.main:app --reload
```

Backend URL:

```text
http://127.0.0.1:8000
```

API docs:

```text
http://127.0.0.1:8000/docs
```

---

## Frontend Setup

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

Frontend URL:

```text
http://127.0.0.1:5173
```

---

## Ollama Setup

Install Ollama and pull the required models:

```bash
ollama pull qwen2.5:1.5b
ollama pull llama3.2:3b
ollama pull llama3.1
ollama pull nomic-embed-text
```

StudyMind AI uses Ollama to run local AI models without a paid API key.

---

## OCR Setup

For image OCR, install Tesseract language packages if needed:

```bash
sudo apt update
sudo apt install tesseract-ocr -y
sudo apt install tesseract-ocr-ara tesseract-ocr-eng tesseract-ocr-heb -y
```

EasyOCR is included in the backend requirements.
